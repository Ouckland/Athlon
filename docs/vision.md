# Athlon — Vision

## What is Athlon?

Athlon is a school football platform for following matches, scores, players, standings, and fantasy football.

The first target is **FUNAAB**.

Athlon should make it easy for students to:

* See upcoming matches
* Follow matches live
* See goals and match events
* Check teams and players
* Follow league standings
* Build a fantasy team
* Compete on a fantasy leaderboard

## Core Idea

Athlon is built around **live match events**.

                                                Real Match
                                                    ↓
                                                Match Event
                                                    ↓
                                                Athlon Backend
                                                    ↓
                                                Score + Stats + Fantasy
                                                    ↓
                                                Live Updates
                                                    ↓
                                                Users

A goal should not be manually updated in multiple places.

One event should update everything that depends on it.

## MVP Goal

Build a working school football platform in one week that can handle:

1. Fixtures
2. Live matches
3. Match events
4. Results
5. League standings
6. Fantasy football
7. Live fantasy points

## Future Direction

Athlon can later support:

* More schools
* More sports
* Advanced statistics
* Notifications
* Social features
* Tournament management
* Better live-data collection
* Automated event detection

These are **not MVP priorities**.
